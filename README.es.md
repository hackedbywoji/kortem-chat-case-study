# Meskify: un asistente de reservas por WhatsApp para negocios con agenda

*Español | [English](README.md)*

Caso de estudio de Meskify, un asistente de IA que se ocupa de las citas por WhatsApp para negocios que viven de su agenda. Un proyecto de equipo entre tres; este repo cuenta el problema, lo que hace el producto y mi parte. El código fuente es privado y seguirá siéndolo.

## El problema

Clínicas, fisioterapeutas, spas, peluquerías y centros de estética funcionan con su agenda. Los clientes escriben fuera del horario de apertura, y un mensaje que espera respuesta puede convertirse en una cita perdida.

## Qué hace

El cliente escribe por WhatsApp. Meskify responde, entiende lo que necesita y se ocupa de la cita.

- Reserva, cancela y modifica citas.
- Envía recordatorios de la cita.
- Gestiona una lista de espera cuando no hay hueco.
- Retoma el contacto con clientes que llevan tiempo sin venir.
- Envía al equipo un resumen semanal.

## Cómo encaja

Funciona por WhatsApp, así que el cliente no necesita instalar otra aplicación. Está disponible fuera del horario de apertura.

## Mi parte

Yo diseñé el agente de IA: cómo es, cómo habla con los clientes y cómo gestiona una cita. También diseñé las APIs sobre las que se construye y la identidad visual del producto.

*Diseño de agentes de IA · Diseño e integración de APIs · identidad visual del producto*

## Por qué este repo no enseña código

El producto es de un equipo y el código es privado. Este caso de estudio deja fuera el cómo a propósito: ni código, ni prompts, ni reglas de negocio, ni flujos internos.
