# Meskify: a WhatsApp booking assistant for appointment-based businesses

*English | [Español](README.es.md)*

A case study of Meskify, an AI assistant that takes care of appointments over WhatsApp for businesses that run on their calendar. A team project built by three of us; this repo covers the problem, what the product does and my part in it. The source code is private and stays private.

## The problem

Clinics, physiotherapists, spas, hair salons and beauty centres run on their calendar. Customers get in touch outside opening hours, and a message that waits for an answer can become a missed appointment.

## What it does

Customers write over WhatsApp. Meskify replies, understands what they need and takes care of the appointment.

- Books, cancels and changes appointments.
- Sends appointment reminders.
- Manages a waiting list when there is no free slot.
- Gets back in touch with customers who have not visited in a while.
- Sends the team a weekly summary.

## How it fits in

It works through WhatsApp, so customers do not need to install another app. It is available outside opening hours.

## My part

I designed the AI agent itself: what it is like, how it talks to customers and how it handles an appointment. I also designed the APIs it is built on and the visual identity of the product.

*AI agent design · API design and integration · product visual identity*

## Why this repo shows no code

The product belongs to a team and the source is private. This case study deliberately keeps the how out: no code, no prompts, no business rules, no internal flows.
